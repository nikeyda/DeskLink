## 凭据存储

连接库同步说明更新为「在两台设备上选择 iCloud 云盘中的同一文件夹，即可同步连接、文件夹和操作偏好。」

同步设置在能识别位置时显示「位置」和「iCloud 云盘」或「本机」。选择应用在本机的文稿文件夹时，时间标签为「上次写入本机」，说明为「当前文件夹在本机。要跨设备同步，请在两台设备上选择 iCloud 云盘中的同一文件夹。」

独立开关为「通过 iCloud 钥匙串同步凭据」。说明为「开启后，保存或移除的远程密码和 SSH 密钥会同步到同一 iCloud 钥匙串。已有本机凭据在下次保存时同步。关闭后仅使用本机凭据。」

## 多显示器会话

连接设置提供「记住上次选择的显示器」。会话中的「选择显示器」菜单包括「所有显示器」及按远端顺序编号的「显示器 1」「显示器 2」等选项。Mac 文件菜单分别使用「新建连接…」和「新建窗口」。

Mac 的显示器菜单提供「在独立窗口中显示」。子窗口以电脑名称和「显示器 2」等编号为标题，尚待首帧时显示「等待远程画面…」，会话结束时显示「连接已结束」。

## 连接信息与触控

点按会话顶部的电脑名称可打开「连接信息」。窗口列出「协议」「传输加密」「桌面像素」，以及「画面与音频」和「已发送的输入」。画面更新显示为「画面编码」「画面更新次数」，视频流显示为「视频编码」「已解码视频帧」「收到的音频包」。另外显示「当前接收速率」「指针事件」和「键盘事件」。窗口使用「完成」关闭。

iPad 设置中的「长按拖动延迟」以秒显示。连接设置中的「连接 Mac 时使用惯性滚动」按电脑单独保存。

## 连接库备份

设置中的「连接库备份」按时间列出备份及其连接数和文件夹数。空列表显示「暂无备份」。说明为「连接库变更时自动备份。此设备保留最近 10 份连接和文件夹记录。密码和密钥保存在钥匙串中。」

选择一份后显示「恢复连接库备份？」及说明「当前连接和文件夹将替换为所选备份。恢复前会保留这台设备上的当前数据。」可选「取消」或「恢复备份」。完成后显示「已恢复」及所选备份的时间。

## 本机听写

「听写」从会话工具栏打开。状态使用「正在准备本机听写…」「正在听写…」「正在识别…」。勾选按钮为「输入到远程电脑」，录音中提示「说完后点右上角的勾，文字将输入到远程电脑。」缺少语言资源时显示「首次使用此语言需要下载 Apple 的本机语音资源。」及「下载语音资源」。

## 从已有电脑创建连接

长按已保存的电脑可选「复制连接」。名称默认在原名称后加「副本」，重名时从 2 开始编号。在「附近」和 Tailscale 的电脑菜单中使用「保存到连接库」，用户可在保存前编辑名称和连接设置。

会话中的相机按钮名为「保存屏幕快照」。系统文件选择器中默认文件名为「远程屏幕快照.png」。还未收到完整画面时显示「请等远程画面显示后重试。」

已保存的电脑可开启「断开时保存桌面快照」。连接菜单提供「查看上次桌面快照」和「清除桌面快照」，查看窗口标题为「上次桌面快照」。

iPad 设置中的「键盘重复」包含「按住时重复」「开始前延迟」和「重复间隔」，时间以毫秒显示。互动工具栏可单独添加 F1–F12、「Return」或任一方向键。

打开「使用安全连接」后，可填写「SSH 服务器」。占位文字为「默认使用桌面地址」。

标准模式使用高色深时，显示设置提供「Mac 自适应画质」与「图像压缩」。每项可选「始终启用」「仅远程连接时启用」或「永不启用」。

最近连接的电脑可查看「上次连接信息」，其中显示「记录时间」和「记录时的接收速率」。旧版连接没有本机记录时显示「此设备尚无这台电脑的连接信息。」

连接库的「更多」菜单可选「排序」。已保存的电脑和收藏提供「自定顺序」「名称」「最近连接时间」「连接次数」「最近修改时间」。最近连接提供后四项，默认按连接时间从近到远排列。

设置中的「新连接默认共享剪贴板」用于后续会话。控制会话的「共享剪贴板」菜单和系统「编辑」菜单提供「自动共享剪贴板」。关闭后仍可使用「发送剪贴板」和「接收剪贴板」。

iPhone 和 iPad 的自动共享只接收远程剪贴板。将本机内容发往远程电脑时，使用「发送剪贴板」。

「连接信息」在视频解码器确认格式前显示「等待视频帧」。旧记录缺少具体格式时显示「未记录视频编码」。「音频播放」显示「已关闭」「未就绪」「等待播放」「播放引擎已启动」或「播放失败」。

高性能连接因视频传输失败而改用标准画面更新时，连接库在这台电脑旁显示带斜线的闪电按钮「立即恢复流畅视频与音频」。显示设置列出「流畅视频与音频将恢复」的日期和时间。

系统文稿类型名为「远程随航归档」。成功导入后显示「导入完成」和「新增连接 N 个，新增文件夹 N 个，跳过重复连接 N 个。」其中的数量按实际导入结果显示。

连接信息在会话发生重连后显示「上次重连原因」。根据客户端实际发起重连的路径，显示「传输连接中断」「传输超时」「应用回到前台」「恢复视频流」「更改连接设置」或「手动重试」。

每台电脑的「Mac 实体键盘」可选「按远端键位输入」和「发送本地字符」。

每台电脑可单独开启「兼容 TigerVNC 首字输入」。说明为「首个按键是 Unicode 扩展字符时，先轻按一次 Shift。」

通过快速连接或网址成功连接的电脑出现在「所有链接」。在电脑菜单中选择「移到链接文件夹」可以整理这些链接。删除链接文件夹时显示“文件夹中的链接会保留在「所有链接」。”

Mac 设置的「这台 Mac」一组提供「登录时打开应用」和「保持这台 Mac 唤醒」。登录项需要 macOS 批准时显示「在系统设置中允许登录项」。唤醒选项的说明为「保持唤醒可让 Mac 在应用运行期间接受远程连接，显示器仍可自动关闭。」

每台电脑的「PC 滚动速度」提供 0.5×、0.75×、1×、1.5× 和 2× 五档，初始为 1×。

附近电脑发现失败时显示「无法查找附近的电脑」和「重新查找」。当系统报告本地网络访问受限时，说明为「请在系统设置中允许远程随航访问本地网络，再重新查找。」

每台电脑的「光标显示」可选「跟随应用设置」「使用本地光标」或「使用远程光标」。iPad 上打开「单独设置长按拖动延迟」后，可以调节这台电脑的「长按拖动延迟」。

iPad 会话的文件传输面板显示「将文件拖到旁边出现的下载区域，松开即可下载。」

原版归档导出遇到 SSH 密钥时的提示示例为“「测试电脑」使用了 SSH 密钥。请使用远程随航归档保留这些设置。”

RSA-AES 连接使用「认证方式」「自动协商」「Raspberry Pi · RSA-AES」「请核对远程计算机的 RSA 公钥指纹。」「记住主机指纹」。连接信息中显示实际协商的「RSA-AES-128」或「RSA-AES-256」。

## 连接库空页面

连接库空页面采用系统文字和操作按钮。设备卡片使用平面系统符号。项目界面不使用拟物设备插画、金属材质渲染或装饰性壁纸。

首次打开「所有连接」显示「添加第一台电脑」和「保存常用电脑，或输入地址连接一次。」可选「新建连接」或「快速连接」。收藏页显示「还没有收藏的电脑」和「在电脑的菜单中选择「添加到收藏」，它就会显示在这里。」最近连接页显示「没有最近连接」和「成功连接过的电脑会显示在这里。」空文件夹显示「文件夹中没有连接」，空链接页显示「没有连接链接」。搜索没有结果时可选「清除搜索」。

## 侧栏显示

在「设置 → 外观 → 侧栏」中，可选择显示「附近」「Tailscale」「所有链接」「最近连接」和「收藏」。开关分组标题为「显示在侧栏」，英文为 “Show in Sidebar”。「所有连接」及自定义文件夹始终显示。

## Siri 与快捷指令

简体中文口令为「用远程随航连接到〈电脑名称〉」，英文口令为 “Connect to 〈computer name〉 with Telescope”。应用名称和电脑名称由系统代入。快捷指令中的英文动作名为 “Connect to Computer”，参数名为 “Saved Computer”。

## Tailscale 设备显示

在设备菜单选「隐藏设备」，可从 Tailscale 菜单中的「隐藏的设备」逐台「恢复显示」。如果目录中的设备全被隐藏，列表提供「查看隐藏的设备」。恢复最后一台后显示「没有隐藏的设备」。

设备菜单的「端口设置」包含「VNC 端口」和「SSH 端口」。提示为「留空使用默认端口。仅在启用安全连接时使用 SSH 端口。」英文名称为 “Port Settings”“VNC Port”“SSH Port”。

## 备用光标

使用本地光标的连接可开启「使用备用光标」。远端主动隐藏指针时显示本地箭头。英文开关名为 “Use Fallback Cursor”。

## VNC 编码

连接编辑器的「显示器 → VNC 编码」可设置 Tight、Tight LastRect、ZRLE、Zlib、CopyRect、Cursor 和 Raw。说明为「允许远端使用所选编码。某些编码取决于远端服务和颜色深度。」英文标题为 “VNC Encodings”。

「显示器」中的「TightVNC JPEG 画质」可从 0 调到 9。在标准全色画面下开启图像压缩且允许 Tight 时可调。英文标题为 “TightVNC JPEG Quality”。

## 后台文件传输

系统进度的标题为「文件传输」，按方向显示「正在从 Mac 下载」或「正在上传到 Mac」。英文副标题为 “Downloading from the Mac” 和 “Uploading to the Mac”。

## 屏幕帘幕

连接设置提供「连接时开启屏幕帘幕」和「远端提示（可选）」，并注明「需要在远程 Mac 开启『远程管理』。」主机确认帘幕状态后，会话栏显示「屏幕帘幕已开启」。

## 光标跟踪速度

连接设置和 iPad 会话的显示菜单提供「光标跟踪速度」。可选「跟随应用设置」或 0.5× 至 2×。会话中更改后即时生效，已存储的电脑沿用新设置。

## Tailscale 文件夹

目录筛选为「文件夹」「所有设备」。可「新建文件夹」「重命名文件夹」「删除文件夹」，并从设备菜单「移到文件夹」或「移出文件夹」。空文件夹显示「此文件夹没有设备」。删除确认显示「文件夹中的设备仍可在『所有设备』查看。」。

## 默认光标模式

iPad 设置的「默认光标模式」可选「直接触控」或「触控板」。连接设置的「光标模式」另提供「跟随应用设置」。会话内切换会保持到该会话结束。

## 连接时缩放

iPhone 与 iPad 的连接编辑器在「显示器」下提供「连接时缩放」，可选「适合屏幕」「填满屏幕」「实际大小」。

## 实体键盘 Option

Mac、iPhone 与 iPad 的「设置 → 控制方式」提供「Option 输入特殊字符」，可选「关闭」「左侧 Option」「右侧 Option」。默认关闭。英文使用「Local Option for Special Characters」「Off」「Left Option」「Right Option」。

## 附近设备数量

iPhone 的「设置 → 侧栏」提供「显示附近设备数量」，英文为 “Show Nearby Device Count”。已发现的设备数量显示在侧栏「附近」旁，数量为零时省略数字。iPhone 和 iPad 在本地网络权限被拒绝时提供「打开系统设置」，英文为 “Open System Settings”。

## 连接诊断

在「设置 → 隐私」进入「连接诊断」，Mac 的「帮助」也提供同一入口。页面包括「导出诊断报告」「最近的连接记录」「最近的连接失败」和空状态「暂无连接诊断」。导出说明为「诊断记录保存在这台设备。导出的报告包含应用版本、系统版本和连接诊断。」导出失败时显示「无法导出诊断报告」。

## iPhone 连接库统一搜索

侧栏和连接分类内的搜索提示为「搜索所有来源」。匹配项按「已保存的电脑」「最近连接」「临时链接」「附近」和「Tailscale」分组。英文新增 “Search All Sources”、“Saved Computers” 和 “Temporary Links”。

## iPhone 与 iPad 的远程应用切换

「设置 → 控制方式」可启用「用 Command–Return 切换远程 Mac 的应用」。英文为 “Switch Remote Mac Apps with Command–Return”。默认关闭。

## Mac 的 VNC 链接默认应用

「设置 → 连接」显示「VNC 链接默认应用」。未找到处理应用时显示「未设置」。使用「设为默认 VNC 应用」后，确认标题为「设为默认 VNC 应用？」，说明为「在此 Mac 上，VNC 链接将默认用远程随航打开。」，操作为「设为默认应用」与「取消」。系统未完成更改时显示「无法设置默认 VNC 应用」，说明为「macOS 未将远程随航设为默认应用。」

## 按住输入用户密码

在工具栏按住「输入用户密码」会打开仅输入密码的确认。说明为「只输入密码，远程表单由你手动提交。」语音辅助操作为「仅输入用户密码」。英文为 “The password will be typed without submitting the remote form.” 和 “Type User Password Only”。
